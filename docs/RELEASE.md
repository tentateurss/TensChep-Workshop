# Windows: установка и обновления

Скачайте `TensChep-Workshop-Windows-x64.zip` из [GitHub Releases](https://github.com/tentateurss/TensChep-Workshop/releases), распакуйте целиком и запустите EXE. Python не нужен. Интерфейс: http://127.0.0.1:8765. Первый запуск скачивает игровые данные; при ошибке сети исправьте подключение и повторите запуск. Для остановки закройте консоль или нажмите Ctrl+C.

## Обновление приложения

В хабе отображаются версия, канал и результат фоновой проверки. Stable исключает предварительные релизы, Beta принимает их. Проверка выполняется не чаще раза в сутки; кнопка ручной проверки обходит кеш. Настройка сохраняется в config/application-updates.json. Ошибка GitHub, включая 403/429, не блокирует приложение.

В portable-версии нажмите «Обновить» и подтвердите установку. «Позже» скрывает предложение в текущей вкладке. Приложение загружает только ожидаемый Windows x64 ZIP и SHA256SUMS.txt из выбранного релиза, проверяет архив и готовит отдельный внешний процесс. Затем основной процесс завершается; помощник дожидается освобождения файлов, сохраняет прежнюю папку, устанавливает новую и проверяет health API с версией и уникальным идентификатором запуска. При обычной ошибке запуска прежняя версия восстанавливается и запускается повторно. Python-версия предлагает ручное скачивание.

**Beta 1 обновляется до Beta 2 вручную:** в опубликованной Beta 1 ещё нет этого установщика. Остановите программу и распакуйте Beta 2 в отдельную папку. Последующие обновления можно устанавливать из интерфейса. Не переносите EXE отдельно от _internal.

## Данные и восстановление

Игровые данные, шаблоны, кеши и резервные копии находятся в `%LOCALAPPDATA%/TensChep Workshop/data`; конфигурация — в соседней config. Установщик их не удаляет и не мигрирует. Обновление RePoE — отдельная команда при остановленном сервере:

```powershell
& '.\TensChep-Workshop.exe' update --expect-version 3.30 --dry-run
```

Совместимость с PoE 3.30 остаётся неподтверждённой. Для отката игровых данных сохраните текущую data под другим именем и верните нужную data.backup-* в data.

Рядом с папкой приложения установщик оставляет `.workshop-update-*` с помощником и installation.json, а также папку `<имя>.previous-*`. После подтверждения работы их можно удалить вручную при остановленных процессах. Не удаляйте резервную копию до проверки.

При аварийном отключении питания автоматическое восстановление не гарантируется. Если папка приложения отсутствует, сохранённый помощник допускает повторный запуск с `--apply-update <полный путь к installation.json>`: при прерывании между переименованиями он возвращает backup. Если обе папки существуют или остался lock, остановите все копии приложения, сохраните новые файлы отдельно и вручную верните previous-папку. Удаляйте `.имя.update.lock` только после проверки отсутствия работающего помощника. Не используйте неизвестные installation.json. Помощник и журнал остаются вне заменяемой папки и не удаляют себя во время работы.

Если нет прав записи или свободного места, установка прекращается с ошибкой. Права администратора не запрашиваются; используйте ручное распаковывание в доступную папку. Повторная попытка допустима после устранения ошибки. Параллельные установки блокируются.

## Сборка и проверки

Windows x64: отдельное venv, `pyinstaller==6.22.3`, затем `python packaging/build_windows.py`. Не собирайте поверх запущенного EXE. Артефакты — в dist. `python packaging/smoke_windows.py` проверяет распакованный архив с изолированными данными и PATH без Python. `python packaging/test_windows_update.py` проверяет установку и откат во временных копиях; baseline находится в игнорируемой `.browser-tools/old-build`. Workflow скачивает опубликованную Beta 1 как baseline, выполняет тесты и только затем публикует prerelease по новому тегу. Старые теги не перемещаются.

Проверены реальная установка и rollback Windows EXE, сохранение шаблонов, повторный запуск, страницы/API и ресурсы без Python в PATH. Браузерный аудит EN/RU/DE на 1920×1080, 1440×900, 1280×720 и 390×844 не выявил ошибок JavaScript или горизонтального переполнения в проверенных начальных состояниях. Длинные реальные планы, все состояния Timeless и отключение питания во время записи — отдельные неполные проверки. Чистые Windows 10/11 на отдельных машинах не проверялись.

## Границы доверия

Проверяются HTTPS, допустимые хосты перенаправлений, размер загрузки, SHA-256, пути ZIP, дубликаты, символические ссылки, Windows reserved names и обязательные ресурсы. HTTP API установки принимает только выбранную сервером версию и защищён loopback/Host/Origin/специальным заголовком. Произвольные URL и команды через него не принимаются.

Цифровая подпись EXE и проверка подписанного manifest пока отсутствуют. SHA-256 относительно того же GitHub Release не защищает от компрометации аккаунта или источника. [GitHub artifact attestations](https://docs.github.com/en/actions/how-tos/secure-your-work/use-artifact-attestations/use-artifact-attestations) рассмотрены, но встроенная проверка происхождения ещё не реализована; не следует считать текущую схему эквивалентом цифровой подписи.

Архив не включает игровые экспорты и личные данные. RePoE указывает права GGG на игровые данные: https://repoe-fork.github.io/. Скачанные таблицы PoB сопровождаются NOTICE. Python поставляется с лицензией; PyInstaller допускает распространение собранных приложений с соответствующим исключением: https://pyinstaller.org/en/stable/license.html.
