# Установка, обновление и восстановление

## Скачать и запустить

1. Откройте [GitHub Releases](https://github.com/tentateurss/TensChep-Workshop/releases). **Beta 4** — предварительный выпуск; стабильность и полнота игровых расчётов ещё имеют ограничения.
2. Скачайте **TensChep-Workshop-Windows-x64.zip**. Скачивайте приложение только со страницы проекта.
3. Распакуйте архив целиком в обычную папку, в которую у вас есть право записи.
4. Запустите **TensChep-Workshop.exe**. Не перемещайте EXE отдельно от папки `_internal`.

Python и pip устанавливать не нужно. При первом запуске нужен интернет для игровых данных. Затем приложение открывается в браузере по адресу **http://127.0.0.1:8765**. Если вкладка не появилась, откройте этот адрес вручную.

Для остановки закройте консоль приложения или нажмите Ctrl+C. Не закрывайте её, пока пользуетесь инструментами.

## Обновить приложение

В главном окне выберите канал:

- **Beta** — предварительные и стабильные выпуски. Подходит для текущих тестовых версий.
- **Stable** — только стабильные выпуски. Если таких выпусков пока нет, канал не предложит Beta.

Workshop проверяет обновления в фоне не чаще раза в сутки. Кнопка **«Проверить обновления»** запускает проверку вручную.

Если новая версия найдена, нажмите **«Обновить»** и подтвердите установку. До подтверждения скачивание обновления не начинается. Программа проверит скачанный архив, сохранит предыдущую папку приложения и перезапустится. **«Позже»** позволяет отложить установку.

Автообновление доступно в Windows-сборке начиная с Beta 2. Из Beta 1 перейдите на новый выпуск вручную. При запуске из исходников используйте инструкции [для сопровождающих](technical/README.md).

### Обновить вручную

Остановите приложение, скачайте новый ZIP и распакуйте его **в отдельную папку**. Запустите новый EXE. Не переносите только один исполняемый файл и не перезаписывайте файлы работающего приложения.

Ручное обновление полезно, если GitHub временно недоступен для автоматической проверки или папка программы закрыта для записи. Права администратора для обхода ограничений не требуются: выберите доступную папку.

## Где находятся ваши данные

В Windows откройте адресную строку Проводника и вставьте:

```text
%LOCALAPPDATA%\TensChep Workshop
```

В `data` находятся игровая база, шаблоны, кеши и резервные копии. В `config` — настройки. Эти папки хранятся отдельно от EXE и сохраняются при обновлении программы.

Чтобы перенести данные на другой компьютер, остановите приложение на обоих компьютерах и скопируйте эту папку. Перед заменой существующих данных сохраните их отдельную копию.

## Обновление игровых данных — отдельное действие

Новый EXE **не переключает базу с PoE 3.29 на 3.30**. Фактическая версия данных видна в Planner. У старой базы без сведений о версии появится отметка «не проверено».

Получение нового экспорта не означает, что Workshop уже поддерживает все новые игровые правила. Перед переходом прочитайте [ограничения PoE 3.30](LIMITATIONS.md#path-of-exile-330).

Обновление данных выполняется отдельно при остановленном приложении, с предварительной проверкой версии и резервной копией. Пошаговая командная инструкция находится в [техническом руководстве](technical/BUILD.md#данные-и-восстановление). Если вы не уверены в этих действиях, сохраните текущую базу и дождитесь разъяснений по нужному экспорту.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Нет сети или не проходит проверка GitHub | Продолжайте работу с установленной версией и повторите проверку позже. Для новых цен и объявлений нужен доступ к источникам. |
| Не хватает места или прав записи | Освободите место либо распакуйте новый ZIP в доступную папку. Не запускайте несколько обновлений одновременно. |
| Новая версия не запускается после автообновления | При обычной ошибке запуска помощник возвращает предыдущую версию. Если этого не произошло, остановите все копии программы и воспользуйтесь сохранённой папкой `.previous-*` рядом с приложением. Сначала сохраните остальные файлы отдельно. |
| Обновление прервалось или отключилось питание | Не удаляйте предыдущую версию и временные папки обновления. Сохраните копию пользовательских данных. Подробные действия восстановления — в [технической инструкции](technical/BUILD.md#данные-и-восстановление). |

Не удаляйте резервные копии, пока не убедитесь, что новая версия работает. Обновление приложения и восстановление игровой базы имеют разные резервные папки; не заменяйте одну другой.

## Безопасность и сторонние материалы

EXE пока не имеет цифровой подписи. Файл `SHA256SUMS.txt` позволяет проверить целостность ZIP, но не защищает от компрометации самого источника релиза. Автоматический откат не гарантирует восстановление после отключения питания или повреждения диска.

Игровые данные не включены в ZIP и загружаются отдельно. Права на Path of Exile и игровые данные принадлежат **Grinding Gear Games**; сведения об источнике — [RePoE](https://repoe-fork.github.io/). Таблицы **Path of Building Community** сопровождаются уведомлением NOTICE. Лицензия Python поставляется с программой. Условия распространения собранных приложений описаны в [лицензии PyInstaller](https://pyinstaller.org/en/stable/license.html).

Для сборки и сопровождения: [техническая документация](technical/BUILD.md). Пользовательское руководство: [как работать с инструментами](README.md).
