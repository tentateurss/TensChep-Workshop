# Windows: установка и сопровождение

Скачайте portable ZIP из [GitHub Releases](https://github.com/tentateurss/TensChep-Workshop/releases), распакуйте целиком и запустите EXE. Python не нужен. Сервер слушает 127.0.0.1:8765. Закройте консоль или нажмите Ctrl+C для остановки.

Первый запуск загружает игровые данные, поэтому нужен интернет. Ошибка отображается в консоли; исправьте подключение и повторите запуск. Готовая база повторно не скачивается. Совместимость с PoE 3.30 не подтверждена.

## Обновление приложения

В хабе отображаются установленная версия, канал и результат фоновой проверки. Stable исключает предварительные релизы; Beta принимает их. Канал сохраняется в config/application-updates.json. Ручная проверка обходит суточный кеш. Ошибка сети не мешает работе.

Доступно ручное скачивание новой версии после проверки. **Автоматический внешний установщик и автоматический откат пока не реализованы.** При обновлении остановите приложение и распакуйте ZIP в отдельную папку; прежнюю папку сохраните для возврата. Пользовательские данные не удаляйте. Beta 2 пока не выпускается, так как сценарий автоматической установки и восстановления не проверен.

## Пользовательские данные

`%LOCALAPPDATA%/TensChep Workshop/data` содержит SQLite, кеши, CLI-шаблоны и резервные копии. Соседняя config содержит резервные цены и настройки проверки обновлений. Ресурсы приложения находятся в _internal; их нельзя переносить отдельно от EXE. Переменные POECRAFT_DATA_DIR и POECRAFT_CONFIG_DIR сохраняют приоритет.

Обновление игровых данных выполняется отдельно при остановленном сервере:

```powershell
& '.\TensChep-Workshop.exe' update --expect-version 3.30 --dry-run
# После появления подходящего экспорта — без --dry-run
```

Для отката игровых данных переименуйте текущую data и верните нужную data.backup-* в data. Перед переносом между компьютерами скопируйте data и config при остановленном приложении.

## Сборка и выпуск

Windows x64: создайте отдельное venv, установите `pyinstaller==6.22.3`, выполните `python packaging/build_windows.py`, затем `python packaging/smoke_windows.py` с подготовленной тестовой базой. Не собирайте поверх работающего EXE: Windows блокирует DLL. Артефакты и SHA256SUMS.txt находятся в dist. Проверьте коды завершения каждого шага.

Workflow Windows portable запускается вручную и по тегу. Сначала выполняет тесты, сборку и smoke, затем создаёт prerelease через GITHUB_TOKEN. SSH Git не предоставляет доступ к Releases API. Не перемещайте существующие теги. Перед Beta 2 обязательны испытания внешнего установщика на двух версиях в изолированной папке и подтверждение наличия архива в опубликованном Release.

## Ограничения безопасности

Сейчас проверка только читает список релизов GitHub и не скачивает/не запускает программы. Отдельная цифровая подпись артефактов отсутствует; SHA-256 сам по себе не защищает от компрометации источника. Автоматическая установка не должна включаться до реализации проверки архива, внешнего процесса и отката.

Архив не включает скачанные игровые экспорты. RePoE указывает, что права на игровые данные принадлежат GGG: https://repoe-fork.github.io/. Уведомления PoB сохраняются при скачивании: https://github.com/PathOfBuildingCommunity/PathOfBuilding/blob/dev/LICENSE.md. Встроенный Python распространяется с лицензией; сведения PyInstaller: https://pyinstaller.org/en/stable/license.html.
