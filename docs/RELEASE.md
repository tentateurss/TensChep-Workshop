# Windows portable Beta 1

Скачайте TensChep-Workshop-Windows-x64.zip из https://github.com/tentateurss/TensChep-Workshop/releases, распакуйте всю папку и запустите TensChep-Workshop.exe. Python и pip не нужны. Не переносите EXE отдельно от _internal. Закройте консоль или нажмите Ctrl+C для остановки. Адрес: http://127.0.0.1:8765.

Первый запуск скачивает игровые данные RePoE и необязательные таблицы PoB/GGG; нужен интернет. Версия источника выводится в консоли. Совместимость с PoE 3.30 не подтверждена: WAITING FOR GAME DATA. При ошибке консоль показывает причину и ожидает Enter. Повторный запуск с готовой базой не скачивает её заново; цены обновляются в фоне.

Данные, шаблоны, кеши и резервные копии находятся в %LOCALAPPDATA%/TensChep Workshop/data, резервные цены — в соседней config. Они сохраняются между версиями EXE; для переноса скопируйте обе папки при остановленной программе. Переменные POECRAFT_DATA_DIR и POECRAFT_CONFIG_DIR переопределяют пути. Неизменяемые ресурсы находятся в _internal.

Обновление из PowerShell: `& '.\TensChep-Workshop.exe' update --expect-version 3.30 --dry-run`, затем без --dry-run после появления нужного экспорта. Перед обновлением остановите сервер. Для отката переименуйте текущую data и верните нужную data.backup-* в data. Не удаляйте резервные копии до проверки.

Сборка Windows x64: создайте отдельное venv, установите `pyinstaller==6.22.3`, выполните `python packaging/build_windows.py`. Runtime-зависимости основного проекта не меняются. Архив и SHA256SUMS.txt появятся в dist. Workflow Windows build запускается вручную и по тегам v*. Для следующего релиза измените текст версии launcher/notes, проверьте тесты и архив, создайте новый тег без перезаписи старого. Публикация требует GITHUB_TOKEN в Actions или авторизованного GitHub CLI.

Архив не содержит игровых экспортов RePoE (их права принадлежат GGG), таблиц PoB, пользовательских данных или секретов. Источники: https://repoe-fork.github.io/ и https://github.com/PathOfBuildingCommunity/PathOfBuilding/blob/dev/LICENSE.md. PoB использует MIT для основной части; скачанные таблицы сопровождаются NOTICE. Интерпретатор Python включён с лицензией; PyInstaller имеет исключение для распространения собранных приложений: https://pyinstaller.org/en/stable/license.html.

Ограничения: неподписанный EXE может вызывать SmartScreen; Windows 10/11 на отдельных чистых машинах требуют проверки. Крафтовые допущения перечислены в docs/LIMITATIONS.md исходного репозитория. Нет гарантии рыночной цены. Сборка не включает браузер; используется установленный браузер Windows.

## Проверки Beta 1

Локальная сборка Windows x64 на Python 3.13.13 / PyInstaller 6.22.3 выполнена. Полный unittest: 194 теста за 52.781 секунды, OK (добавлен тест packaged-путей и сохранения пользовательской конфигурации). compileall успешен.

Распакованный ZIP проверен из временного пути с пробелами и кириллицей при PATH без Python: CLI, HTTP health, главная, craft, evaluator, JS/CSS, locale, meta/rules, повторный запуск — OK. Для offline integration использована копия локальных игровых raw/SQLite только во временном профиле. В ZIP этих данных нет. Первый запуск без базы с недоступным источником показывает ошибку; упакованный CLI дочернего update запускается. Чистые Windows 10 и Windows 11 на отдельных машинах, SmartScreen и визуальное открытие браузера — NOT TESTED.

GitHub CLI отсутствует, GH_TOKEN/GITHUB_TOKEN локально отсутствуют. Доступ SSH не является доступом Releases API. Workflow по тегу создаёт pre-release собственным GITHUB_TOKEN; фактическая публикация должна проверяться в Actions/Releases. Пока подтверждения нет, релиз не считается опубликованным.
