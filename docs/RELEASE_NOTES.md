# TensChep Workshop v1.0.0 Beta 5

- Новый **Build Assistant**: открывайте билды PoE 1 по ссылке pobb.in, экспортному коду Path of Building или XML-файлу.
- Просматривайте класс, Ascendancy, уровень, деревья пассивов, группы камней и комплекты экипировки. Подтверждённые авторские варианты можно переключать вместе; остальные наборы выбираются независимо.
- Предупреждение показывает различие версий дерева и игровых данных Workshop. На телефоне доступны компактный обзор и раскрываемые группы.
- Сохранены Craft Planner, Recovery, адаптивный поиск редких предметов и точный поиск русских Unique, включая «Знак Каома».

Для обновления с Beta 4 выберите канал **Beta**, нажмите **«Проверить обновления»**, затем **«Обновить»**. Либо скачайте ZIP и распакуйте его в отдельную папку. Python не требуется; при первом запуске без игровых данных нужен интернет.

Обновление приложения сохраняет базу, настройки и шаблоны в `%LOCALAPPDATA%\TensChep Workshop` и не обновляет игровые данные. Build Assistant пока не содержит гайд по актам, интерактивную карту дерева или собственный расчёт DPS. Полная поддержка правил PoE 3.30 не подтверждена; Timeless 3.30 остаётся непроверенным. Незавершённая работа Essence of Trickery не включена.

EXE не подписан. SHA-256 проверяет целостность ZIP относительно контрольной суммы релиза. [Установка и восстановление](https://github.com/tentateurss/TensChep-Workshop/blob/main/docs/RELEASE.md).
