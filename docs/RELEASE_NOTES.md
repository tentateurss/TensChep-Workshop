# TensChep Workshop v1.0.0 Beta 4

- Исправлен точный поиск русских уникальных предметов, включая «Знак Каома»: учитываются имя, база и распознанные свойства.
- Небольшие значения валют больше не округляются до нуля; неизвестный курс не подменяется выдуманным.
- Цена подходящего объявления видна сразу. Предупреждения о большом разбросе цен и неподтверждённых свойствах сохранены.
- Сохранены адаптивный поиск редких предметов и специальная оценка Timeless Jewels с проверкой совместимости данных.

Для обновления с Beta 3 выберите канал **Beta**, нажмите **«Проверить обновления»**, затем **«Обновить»**. Либо скачайте ZIP и распакуйте его в отдельную папку. Python не требуется; при первом запуске без игровых данных нужен интернет.

Обновление приложения сохраняет базу, настройки и шаблоны в `%LOCALAPPDATA%\TensChep Workshop`. Оно не обновляет игровые данные. Полная поддержка правил PoE 3.30 не подтверждена; Timeless 3.30 остаётся непроверенным. Незавершённая поддержка Essence of Trickery в этот выпуск не включена.

EXE не подписан. SHA-256 проверяет целостность архива относительно контрольной суммы релиза. [Установка и восстановление](https://github.com/tentateurss/TensChep-Workshop/blob/main/docs/RELEASE.md).
