# Навигация и безопасная работа

TensChep Workshop — локальные инструменты Path of Exile 1: планирование крафта, оценка предметов и Timeless Jewels.

Сначала прочитайте [карту кода](docs/CODEMAP.md) и относящиеся к задаче [ограничения](docs/LIMITATIONS.md). Если локальный Graphify доступен, запросите нужный участок графа до поиска по всему репозиторию. Затем читайте только затронутые модули и диапазоны. Не перечитывайте неизменённые файлы; используйте diff и ранее найденные сведения. Повторно используйте существующие функции. После правок исходников выполните `graphify update . --no-cluster`.

Команды: `python -m poecraft serve --no-browser`, `python -m unittest discover -s tests`, `python -m compileall -q poecraft`. Сборка Windows: `python packaging/build_windows.py` в отдельном build-окружении; проверки описаны в [RELEASE.md](docs/RELEASE.md).

Не обновляйте рабочую SQLite ради тестов. Проверяйте изменения данных на копиях через staging, с резервными копиями и контролем версии/совместимости. Не выдавайте неизвестные версии за подтверждённые. Не выдумывайте вероятности, веса или цены.

Изменения поведения требуют регрессионных тестов и проверки существующих сценариев: worked example, --have, цены/лиги, локализация, API; для упаковки — Windows smoke и rollback. Экономия чтения не отменяет тестирование, обработку ошибок и проверки безопасности. Отчитывайтесь кратко: изменение, проверка, ограничения.

Для библиотек, SDK и CLI сначала запрашивайте актуальную документацию Context7: resolve-library-id, затем query-docs по конкретному вопросу.
